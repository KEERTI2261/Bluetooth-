# Bluetooth-
Bluetooth Based Home Automation.

The main objective of this project is to provide a simple, efficient, and cost-effective solution for controlling home appliances wirelessly. By using Bluetooth communication, users can operate electrical devices through a mobile application without the need for physical switches.
In this system, the Bluetooth module receives commands from a smartphone and transmits them to the ARM7 LPC2129 microcontroller. Based on the received commands, the microcontroller controls the connected appliances through relay circuits. This enables users to turn devices ON or OFF conveniently within the Bluetooth communication range.
