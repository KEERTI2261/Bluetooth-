# Bluetooth-

MINI PROJECT : Bluetooth Based Home Automation System

Introduction:-
      The Bluetooth Based Home Automation System is a smart embedded system designed to
control household electrical appliances wirelessly using Bluetooth communication. The project
aims to provide users with a convenient, efficient, and cost-effective method for operating home
devices through a mobile phone. This system eliminates the need for manual switching and
enhances user comfort by enabling wireless control of appliances.

Objective:-
     The primary objective of this project is to develop a home automation system that allows
users to control electrical appliances remotely through Bluetooth technology using an ARM7
LPC2129 microcontroller.

Hardware Components:-
➢ ARM7 LPC2129 Microcontroller
➢ Bluetooth Module (HC-05)
➢ Relay Module
➢ Power Supply Unit
➢ Electrical Load (Bulb/Fan)
➢ Mobile Phone with Bluetooth Application

Working Principle:-
      The system operates through Bluetooth communication between a smartphone and the
Bluetooth module connected to the ARM7 LPC2129 microcontroller. When a user sends a
command through the mobile application, the Bluetooth module receives the command and
forwards it to the microcontroller via UART communication. The microcontroller processes the
received data and controls the corresponding relay circuit. The relay then switches the connected
appliance ON or OFF based on the command received.

Block Diagram:-
  Smart Phone-->Bluetooth module(HC-05)-->LPC2129 MC-->Relay Modules-->Home Appliances(light,fan).

Applications
➢ Smart Home Automation
➢ Wireless Appliance Control
➢ Energy Management Systems
➢ Office Automation
➢ Industrial Monitoring and Control

Advantages
➢ Easy to operate
➢ Low cost implementation
➢ Reliable wireless communication
➢ Energy efficient

Conclusion
     The Bluetooth Based Home Automation System successfully demonstrates the application of
embedded systems and wireless communication in modern home automation. Using the ARM7
LPC2129 microcontroller and Bluetooth technology, the system provides a simple and effective
method for controlling electrical appliances. This project enhanced practical knowledge in
Embedded C programming, microcontroller interfacing, and UART communication.
